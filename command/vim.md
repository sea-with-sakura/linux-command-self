vim
===

一款功能强大的模式化终端文本编辑器，是 Linux 系统下最主流的代码编写与文本处理工具。

## 补充说明

**vim 命令** 全称为 Vi IMproved，是基于经典 vi 编辑器扩展升级而来的终端文本编辑器，是 Linux/Unix 服务器环境中最常用的编辑工具。它支持语法高亮、代码折叠、宏录制、正则批量替换、多窗口编辑、插件扩展等丰富特性，常见使用场景包括服务器配置文件修改、程序代码开发、日志文本查看编辑、纯文本撰写等。

vim 采用多模式的交互设计，不同模式下按键功能完全不同，这是其核心特点也是新手的主要学习门槛，使用时需先明确当前所处模式，核心模式分为普通模式、插入模式、命令行模式、可视模式四类，按 `Esc` 键可随时回到默认的普通模式。

### 语法

```shell
vim [选项] [文件...]
```

### 选项

- `-h, --help`: 显示 vim 命令的帮助信息
- `-v, --version`: 显示 vim 的版本号与编译配置信息
- `+<行号>`: 打开文件后光标直接跳转到指定行号位置
- `+/<关键词>`: 打开文件后直接定位到第一个匹配关键词的行
- `-d, --diff`: 以差异对比模式打开多个文件，高亮显示文件内容的区别
- `-o`: 水平分屏打开多个文件
- `-O`: 垂直分屏打开多个文件
- `-R, --readonly`: 以只读模式打开文件，避免误修改内容
- `-u <配置文件>`: 指定自定义 vim 配置文件启动，跳过默认配置加载

### 核心模式与常用操作

vim 启动后默认处于普通模式，输入的所有字符都会被当作命令执行；通过对应按键可切换到其他模式完成不同操作。

1. **模式切换**
- 普通模式 → 插入模式：按 `i` 在光标前插入，按 `a` 在光标后插入，按 `o` 在光标下方新建行并插入
- 普通模式 → 命令行模式：按 `:` 键，输入命令后回车执行，执行完成自动回到普通模式
- 普通模式 → 可视模式：按 `v` 进入字符可视模式，按 `V` 进入行可视模式，按 `Ctrl+v` 进入块可视模式

2. **普通模式常用操作**
- 光标移动：`h` 向左、`j` 向下、`k` 向上、`l` 向右
- 删除操作：`dd` 删除整行，`x` 删除光标处单个字符
- 复制粘贴：`yy` 复制整行，`p` 将复制内容粘贴到光标下方
- 撤销重做：`u` 撤销上一步操作，`Ctrl+r` 重做被撤销的操作
- 查找内容：输入 `/关键词` 向下查找，输入 `?关键词` 向上查找，按 `n` 跳转到下一个匹配项

3. **命令行模式常用操作**
- `:w` 保存当前文件
- `:q` 退出 vim
- `:wq` 保存文件并退出
- `:q!` 强制退出，不保存修改
- `:set nu` 显示行号，`:set nonu` 隐藏行号
- `:%s/旧内容/新内容/g` 全文范围内将旧内容替换为新内容

### 实例

打开单个文本文件进行编辑
```shell
vim test.txt
```

打开配置文件并直接跳转到第 50 行
```shell
vim +50 nginx.conf
```

垂直分屏同时打开两个配置文件对比编辑
```shell
vim -O app.conf database.conf
```

以差异对比模式打开两个版本的代码文件
```shell
vim -d v1/main.py v2/main.py
```

以只读模式打开运行日志，防止误修改
```shell
vim -R server_run.log
```

打开日志文件并直接定位到第一个包含 "error" 的行
```shell
vim +/error run.log
```
